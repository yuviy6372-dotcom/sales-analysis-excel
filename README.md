# Sales Performance Dashboard - Excel

## Project Overview

An interactive Sales Performance Dashboard created using Microsoft Excel
to analyze sales trends, product performance, categories, brands, and
order-related information.

The project focuses on data cleaning, data transformation, lookup
functions, PivotTables, PivotCharts, slicers, and dashboard design.

## Tools & Skills Used

- Microsoft Excel
- XLOOKUP
- Data Cleaning
- PivotTables
- PivotCharts
- Slicers
- Data Analysis
- Dashboard Design

## Dashboard Analysis

The dashboard provides insights into:

- Sales performance by category
- Sales performance by brand
- Monthly sales trends
- Top 10 products by sales
- Order status distribution
- Gender-based filtering
- Category and brand filtering

## Interactive Features

The dashboard includes slicers that allow users to filter the
visualizations based on:

- Category
- Order Status
- Gender
- Brand

## Project Structure

- `Sales_Performance_Dashboard.xlsx` - Complete Excel workbook
- Supporting worksheets contain the underlying sales data and analysis.

This project helped me develop practical skills in Excel data analysis,
